Overview

One field. Six connected perspectives.

Security capability emerges from data, training, and the systems that turn model outputs into verified action.

From the abstract

Advances in language understanding, code reasoning, and tool use are enabling cybersecurity agents to progress from question answering and single-step analysis to vulnerability research, incident investigation, and multistage task execution. This survey examines research on Large Language Models (LLMs) for cybersecurity across six dimensions: data, training, models, agent systems, evaluation, and applications.

We argue that cybersecurity LLMs are progressing from acquiring domain knowledge to learning how to perform interactive tasks. Task quality and cost depend on both the model and its harness: the model reasons and selects actions, while the harness organizes information, tools, and execution state.

Future directions

Adversarial interaction drives intelligence; intelligence advances security.

Four directions from Section 9.8 for turning stronger capability into lasting security benefit.

01

AI‑native security architectures

Build perception, reasoning, decisions, and feedback learning in from the outset; validated experience feeds further learning.

02

Transferable failure recovery

Diagnose invalid hypotheses, tool faults, and interrupted paths, then choose alternatives while retaining useful findings.

03

Alternating model–⁠harness updates

Revise the harness from failures, update the model on the resulting interactions, and test whether gains transfer.

04

From discovery to remediation

Track backlogs, confirmed and resolved issues, review hours, and exposure duration over time.
